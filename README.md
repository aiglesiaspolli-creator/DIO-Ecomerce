# 🛒 DIO E-commerce Database
> Modelagem Relacional, Povoamento e Consultas SQL para Gerenciamento de E-commerce

Este projeto foi desenvolvido como parte do curso de Banco de Dados SQL na **Digital Innovation One (DIO)**, sob orientação da instrutora **Juliana Mascarenhas**. O objetivo principal foi criar a estrutura completa de um banco de dados relacional para gerenciar o ecossistema de um e-commerce, englobando o fluxo de clientes, produtos, estoques, fornecedores, pedidos e pagamentos.

---

## 📌 Destaques do Projeto

- **Modelagem de Dados (DDL):** Criação de tabelas com chaves primárias, estrangeiras e restrições integras para representar o modelo entidade-relacionamento do e-commerce.
- **Povoamento do Banco (DML):** Inserção de dados de teste (*seeds*) para simulação do ambiente operacional de vendas e estoque.
- **Consultas Analíticas (DQL):** Scripts de consulta utilizando JOINs, agrupamentos (GROUP BY), filtros e ordenações para extração de métricas de negócio.

---

## 🛠️ Tecnologias e Ferramentas

- **SQL (Structured Query Language):** Linguagem utilizada para definição, manipulação e consulta dos dados.
- **SGBD Relacional:** MySQL / PostgreSQL / Workspaces SQL.
